# String Transformers 🔤

A collection of utility functions to transform strings for various use cases, such as formatting, case conversion, and cleaning input data.

## 🔗 Live Demo  
<a href="https://amruthacgowda.github.io/string-transformers" target="_blank">Check here</a>

## 🛠️ Technologies Used

- **HTML5**
- **JavaScript (ES6 Modules)**

## 🚀 Features

- Convert strings between different cases:
  - `camelCase`
  - `snake_case`
  - `kebab-case`
  - `PascalCase`
- Capitalize or lowercase words
- Strip or sanitize unwanted characters
- Custom string manipulation utilities for cleaner, formatted output
